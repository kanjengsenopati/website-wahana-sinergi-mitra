# CV. WAHANA SINERGI MITRA (Contractor) - Landing Page

Landing page resmi berstatus *"Dalam Perencanaan"* untuk perusahaan kontraktor **CV. WAHANA SINERGI MITRA**, dibangun dengan **Vite + React + Tailwind CSS** mengikuti standar PakRT Premium Native Layouting Rules.

## 🚀 Fitur Utama
- **Countdown Timer 60 Hari**: Perhitungan waktu mundur akurat menuju peluncuran resmi.
- **Identitas Brand & Logo**: Visual premium dengan logo resmi WSM Contractor.
- **Background Konstruksi**: Latar arsitektur konstruksi bangunan dengan overlay modern.
- **Layanan Utama**: Ringkasan bidang konstruksi (Gedung, Sipil, Renovasi, Desain Interior).
- **Quick Action**: Tombol kontak WhatsApp & Email langsung.

## 🛠️ Panduan Pengembangan Lokal
```bash
# Instal dependensi
npm install

# Jalankan server lokal
npm run dev

# Build untuk produksi
npm run build

# Preview hasil build
npm run preview
```
